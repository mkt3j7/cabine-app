Privacy policy

Cabine is a personal automation app that publishes videos to one YouTube channel: the channel owned by the person who runs it. There are no other users, no accounts to sign up for, and nobody else's data passes through it.

What we request from Google

  • youtube (upload and manage videos) — used only against the owner's own channel.
  • yt-analytics.readonly (read reports about your videos) — used only to read the owner's own channel's reports.

Cabine requests no other Google scopes. It does not ask for email, profile, Drive, Gmail, contacts, or any non-YouTube scope.

What is stored, and where

  • The OAuth access and refresh token for the owner's channel, kept as a JSON file on the machines that run the automation and in that repository's encrypted secrets. It is never sent to any third party and never displayed.
  • The OAuth client secret, kept in the same encrypted secrets.
  • Video files and the scripts behind them, which are the owner's own content.
  • YouTube analytics numbers read back by the app, kept locally and used only to pick future topics for the same channel.

What is never collected

No personal information about any viewer. No cookies, no tracking scripts, no analytics on this web page. Nothing is sold, shared, or transferred to third parties, and no human review of anyone else's content takes place.

Who can see it

Only the person who owns the channel and runs the automation. The app has no multi-user mode.

How to revoke access

At any moment, without touching this app: open myaccount.google.com/permissions, find Cabine, and click Remove access. The refresh token stops working immediately. Deleting the token file from the automation machines removes the last copy of it.

Changes

If the app ever asks for a new Google scope, this page is updated before that scope is used, and the header below carries the date.
