Cabine

Channel automation for exactly one YouTube channel: the one that owns this app.

What it does

Cabine is a personal tool I run for my own channel. On a schedule it takes the topic list I have written, renders the video files, and uploads them to my channel through the YouTube Data API. It publishes nothing that I have not already scripted, and it only ever writes to the one channel that authorised it.

What it asks YouTube for

  • youtube — upload and manage videos on my own channel.
  • yt-analytics.readonly — read my own view and retention numbers, so the next topic list can be built from what actually worked.

Cabine does not browse other people's channels, does not read other people's accounts, and has no server of its own listening for anything. It is an installed application that runs on scheduled machines I control, in a private repository I own.

Who runs it

One person. There is no team, no company behind it, and no other user can sign in — the OAuth client exists solely to let the owner's channel talk to the owner's automation.
